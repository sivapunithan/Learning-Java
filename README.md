# Learning-Java

A Java-only DSA and fundamentals practice repo, organized by topic.

## Topics

- [Arrays](Arrays) — array manipulation problems: finding largest/second-largest elements, filtering negatives, removing duplicates/elements, merging sorted arrays, and similar array exercises.
- [Basics](Basics) — core Java fundamentals: loops, methods, even/odd checks, and other beginner practice.
- [LinkedList](LinkedList) — singly linked list problems: cycle detection (Floyd's algorithm), reversing, palindrome check, removing nodes, and intersection detection.
- [Math](Math) — number-theory style exercises: digit counting, palindrome number checks.
- [OOPS](OOPS) — object-oriented programming introduction and examples.
- [PatternPrinting](PatternPrinting) — nested-loop pattern printing: triangles, pyramids, and toggle patterns.
- [Recursion](Recursion) — recursive solutions: factorial, Fibonacci, power of two, and array sums.
- [SearchAndSorting](SearchAndSorting) — search and sorting algorithms: binary/linear search, bubble/insertion/selection/merge sort.
- [Socket](Socket) — basic client/server socket programming examples.
- [Java-Fundamentals](Java-Fundamentals) — additional fundamentals notes and I/O practice.
- [Production-Learning](Production-Learning) — misc. production/DOA notes.

See [NOTES.md](NOTES.md) for consolidated day-by-day learning notes, organized by topic.
